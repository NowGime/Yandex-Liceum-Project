# Больница: учёт пациентов

Проект по курсу Яндекс Лицея. Настольное приложение на Python (PyQt6) для работы со списком пациентов больницы. Данные хранятся в базе SQLite.

## Пояснительная записка

### Идея проекта

Приложение помогает персоналу больницы вести список пациентов. При запуске пользователь входит в систему под своим логином и паролем. После входа открывается таблица пациентов, а набор доступных действий зависит от роли пользователя.


### Возможности

- Авторизация по логину и паролю, сообщения об ошибках входа.
- Таблица пациентов с полями: ФИО, дата рождения, диагноз, палата, дата поступления.
- Добавление, изменение и удаление пациентов (в зависимости от роли).
- Поле «Палата» принимает только цифры.
- Даты вводятся через календарь в формате `дд.мм.гггг`, будущие даты выбрать нельзя. Дата поступления не может быть раньше даты рождения.
- Администратор может создавать новых пользователей (с выбором роли) и удалять созданных.
- Встроенные учётные записи `admin`, `doctor` и `nurse` удалить нельзя.
- Выход из аккаунта и возврат к окну входа.

### Используемые технологии

- Python 3
- PyQt6 (графический интерфейс)
- SQLite, модуль `sqlite3` из стандартной библиотеки (база данных)


### Как устроена программа

1. `main.py` создаёт таблицы в базе (если их нет) и показывает окно входа.
2. `LoginWindow` проверяет логин и пароль в таблице `users` и передаёт роль дальше через сигнал `logged_in`.
3. По сигналу открывается `MainWindow`. Набор кнопок формируется по словарю прав `PERMISSIONS`.
4. Добавление и изменение пациентов выполняются через окно `PatientDialog`, где проверяются введённые данные.
5. При выходе из аккаунта главное окно закрывается и снова показывается окно входа.


## Инструкция для пользователя

### Установка и запуск

1. Установите Python 3 с сайта python.org, если он ещё не установлен.
2. Скачайте папку с проектом и убедитесь, что файлы `main.py` и `auth_window.py` лежат в одной папке.
3. Откройте терминал в папке проекта.
4. Создайте виртуальное окружение (если папки `.venv` ещё нет):

   ```
   python -m venv .venv
   ```

5. Активируйте его. В вашей командной строке (Windows - PowerShell; Linux - Konsole):

   ```
   source .venv/bin/activate
   ```

   В начале строки терминала появится `(.venv)`.

6. Установите все нужные библиотеки из файла `requirements.txt` в активированное окружение:

   ```
   pip install -r requirements.txt
   ```

7. Запустите приложение любым удобным вам способом или командой:

   ```
   python main.py
   ```

   При первом запуске автоматически создаётся файл `hospital.db` с тестовыми данными.

При следующих запусках достаточно активировать окружение (шаг 5) и выполнить шаг 7.

### Работа с приложением

1. **Вход.** В окне авторизации введите логин и пароль и нажмите «Войти» (или клавишу Enter). Тестовые аккаунты:

   | Роль | Логин | Пароль |
   |------|-------|--------|
   | Администратор | `admin` | `admin123` |
   | Врач | `doctor` | `doctor123` |
   | Медсестра | `nurse` | `nurse123` |

2. **Просмотр.** После входа откроется таблица пациентов. Строка выбирается щелчком мыши и подсвечивается синим.

3. **Добавление пациента** (администратор и врач). Нажмите «Добавить», заполните поля и нажмите «Сохранить». Номер палаты вводится цифрами, даты выбираются через календарь.

4. **Изменение пациента** (администратор и врач). Выберите строку в таблице, нажмите «Изменить», поправьте данные и нажмите «Сохранить».

5. **Удаление пациента** (только администратор). Выберите строку, нажмите «Удалить» и подтвердите действие.

6. **Создание пользователя** (только администратор). Нажмите «Новый пользователь», введите логин и пароль, выберите роль и нажмите «Создать».

7. **Удаление пользователя** (только администратор). Нажмите «Удалить пользователя», выберите логин из списка и подтвердите удаление. Аккаунты `admin`, `doctor` и `nurse` в списке не отображаются и удалены быть не могут.

8. **Выход.** Нажмите «Выйти из аккаунта», чтобы вернуться к окну входа и зайти под другим пользователем.
